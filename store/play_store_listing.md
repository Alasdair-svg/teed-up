## Permissions Justification

| Permission | Justification |
|---|---|
| `CAMERA` | Used to capture photos of golf booking confirmations for OCR scanning |
| `READ_EXTERNAL_STORAGE` | Used to import booking confirmation screenshots from gallery |
| `READ_CALENDAR` / `WRITE_CALENDAR` | Used to create calendar events and monitor RSVP responses |
| `READ_CONTACTS` | Used to select playing partners for calendar invitations |
| `RECEIVE_BOOT_COMPLETED` | Used to restart background decline-monitoring after device reboot |

| `POST_NOTIFICATIONS` | Used to deliver decline alerts and booking reminders |
